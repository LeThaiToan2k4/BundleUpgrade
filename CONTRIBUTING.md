# Contributing to Bundle Upgrade

Contributions are welcome! Please follow these guidelines:

1. Target Java 21 and Minecraft 1.21.11.
2. Run `./gradlew build` to ensure the project compiles cleanly.
3. Keep Mixins minimal, clean, and well-documented.
4. Ensure both English (`en_us.json`) and Vietnamese (`vi_vn.json`) localization files are updated for any new user-facing strings.
